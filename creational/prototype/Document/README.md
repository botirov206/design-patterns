# Prototype — Document

Java project for the Prototype pattern document example.

## Project layout

```
src/
  Main.java
```

Open this folder in IntelliJ IDEA (`Document.iml`) or in VS Code / Cursor. Source lives in `src`, and compiled classes go to `out`.

## Requirements

Java 17 or newer.

## Run

From this directory:

```bash
javac -d out src/*.java
java -cp out Main
```
